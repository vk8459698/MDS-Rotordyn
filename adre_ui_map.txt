ADRE UI map
===========

Mapped steps (live dump 2026-09-09 from this machine)
-----------------------------------------------------
Open database:
  1. Visible toolbar Open on ADRE® Sxp (m_GeneralToolBar). File → Open /
     Database Manager exist but are visible=False until File is expanded.
  2. Database Manager is a CHILD dialog of ADRE, not a top-level window.
     auto_id=DatabaseManagerForm  class=WindowsForms10.Window.8.app...
  3. Grid auto_id=m_obGrid name=FlexGrid. UIA titles are "Row N Column M"
     only. Real text is LegacyIAccessible Value:
       col 3 = Name (e.g. 3_GE_7HA)
       col 4 = Path/Address
       col 7 = Availability
  4. Click Name cell, then Button Open auto_id=m_OpenButton
     (Cancel=m_CancelButton Apply=m_obApplyButton Help=m_HelpButton).
  5. Add Database / Add Connection / Remove From List / Refresh Status
     are toolbar MenuItems on the dialog (not Buttons).

Do not search Desktop.windows() for "Database Manager" — it will miss.
Do not click Cursor's File menu (desktop-wide title match).
Before every click: SetForegroundWindow on ADRE (hwnd). If Cursor covers ADRE,
click_input lands on Cursor even when the target control is on ADRE.
Move/snap Cursor aside before --try-export.
Open database toolbar: auto_id=m_GeneralToolBar → MenuItem Open (not File menu).
Add Database toolbar on dialog: auto_id=m_c1ToolBar → MenuItem Add Database.
Match database by Name column even when vault path changed (new import id).
Select the database name in Configuration Hierarchy (collapsed). Do not
expand ADRE 408 or sampling cards. Right-click 3_GE_7HA → Plots →
Tabular List / Timebase. That includes every channel on the database.

HV - Plot Session is a CHILD of ADRE® Sxp, not a top-level window.
  auto_id=PlotSessionWindow  title='HV - Plot Session'
Plot group child:
  auto_id=PlotGroupWindow  title='New Tabular List Plot Group - Plot Group [...]'
Bottom Export Plots (the small icon / tooltip, NOT the HV top toolbar):
  pane auto_id=pnlBottom
  toolbar auto_id=m_c1PlotGroupToolBar  MenuItem title='Export Plots'
Do not click the large top Export Plots next to Print / Create Replay Database.

Top-level windows (uia):
  - 'Taskbar'
  - 'adre_export_recipe.json - RotorDyn - Cursor'
  - 'ADRE® Sxp'
  - 'Program Manager'
